🚀 Web Editor

A lightweight, standalone code editor Web Component built with Angular Elements and CodeMirror 6

📦 Usage

Simply include the script and use the <web-editor> tag:

<script src="dist/web-editor.js"></script>

<web-editor
  language="typescript"
  theme="dark"
  value="console.log('Hello World!')"
  height="400px">
</web-editor>
