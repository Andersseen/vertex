# Support

Thanks for using Vertex.

## How to Get Help

- Usage questions and general help: open a GitHub Discussion (if enabled) or a GitHub Issue.
- Bug reports: open an issue with clear reproduction steps, expected behavior, and logs.
- Security reports: follow [SECURITY.md](SECURITY.md). Do not open public security issues.

## What to Include

When asking for help, please include:

- Vertex version or commit SHA
- Operating system and version
- Bun and Node versions
- Exact command you ran
- Error output and relevant logs
- Minimal reproduction project or steps

## Response Expectations

This is an open source project maintained as time permits. We will do our best to respond, but response times may vary.

## Commercial Support

No commercial support SLA is currently offered.
