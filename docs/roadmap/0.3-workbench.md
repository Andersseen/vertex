# 0.3 — Shared workbench and documents

Status: pending. Depends on 0.2. Contracts: C1, C3, C4, C8.

**User outcome:** browser and desktop share session behavior. Switching tabs,
opening preview, or renaming cannot destroy undo history, focus, or text.

## Ordered tasks

### V03-01 — Extract the document controller

- Paths: web EditorSessionService, `apps/desktop/src/app/app.ts`, core services,
  and shared types.
- Move document opening, activation, closing, revisions, and identity into one shared
  controller. Use a temporary compatibility adapter and migrate one surface at a time.
  Connect V02-04's queue instead of copying its logic.
- Closing a dirty document supports save/discard/cancel with recovery. Closing an
  additional view does not discard its shared document.
- **Acceptance:** identical session scenarios pass with browser/native adapters;
  save/rename failures retain correct active/dirty state. Apps do not own competing
  authoritative document arrays.

### V03-02 — Per-document CodeMirror state

- Paths: shared editor component, editor-core configurator, tabs, and tests.
- Preserve undo, selection, and scroll per document. Activate the correct state on
  switching rather than replacing all text as an ordinary edit transaction.
- Distinguish external updates from local input; shared views converge without a
  second authoritative text store.
- **Acceptance:** A03 covers A→B→undo→A, empty files, and twenty tab switches. Undo in B
  never inserts A's content. Returning to A preserves selection and history.

### V03-03 — Reconfigure language, extensions, and theme safely

- Paths: editor component, editor-core compartments/registry, shared TS extensions.
- Reconfigure when document/extensions/preferences change. Diagnostic closures cannot
  retain a previous path. Ignore late language loads after switching/disposal.
- Preserve IME/history when toggling preview and avoid recreating the editor merely
  because the page chooses another template branch.
- **Acceptance:** delayed JS→JSON→TS changes end with the correct language; B's edits
  never diagnose A. Theme/panel changes preserve selection, content, and undo.

### V03-04 — Extract workspace operations from screens

- Paths: web editor page, desktop app, core controllers, and shared UI panels.
- Move workspace switching, explorer selection, and save orchestration into small
  controllers with clear responsibilities. Apps compose adapters and routing.
- Split components according to AGENTS.md incrementally. Do not replace a large page
  with an equally oversized WorkbenchService.
- **Acceptance:** existing journeys pass using common controllers on both surfaces;
  view teardown disposes subscriptions without deleting documents.

### V03-05 — Real framework coverage and session regressions

- Paths: core/ui/editor-core tests and E2E; dependency guard where relative imports
  could evade existing checks.
- Separate pure logic tests from real Angular behavior. Exercise signals/effects,
  input changes, and destruction without a global framework replacement.
- Add save-during-close, slow file load, project switching, and stale-read scenarios.
- **Acceptance:** A01–A03 and both application builds pass; standalone editor remains
  independent. Record migrated/removed contracts for the next milestone.

## Exit demonstration

Edit/undo independently in two documents, toggle preview, change theme, and rename
without losing state. Repeat with the available native adapter, recording filesystem
gaps for 0.4 rather than duplicating product logic to work around them.
