# 0.4 — Native macOS platform

Status: pending. Depends on 0.3. Contracts: C1–C5 and C9. Windows/Linux are outside
this installed milestone.

**User outcome:** the installed application opens and modifies a local folder with
coherent permissions, errors, and external-change handling.

## Ordered tasks

### V04-01 — Register the native adapter at bootstrap

- Paths: desktop app configuration, `core/src/fs/file.service.ts`, TauriService,
  `apps/desktop/src-tauri/src/lib.rs`, and shared contracts.
- Implement filesystem/capability contracts through Tauri. The browser registers its
  own adapter and does not contact localhost just because no project is open.
- Retain sidecar compatibility only for declared environments. Inventory consumers
  before removing legacy backends.
- **Acceptance:** macOS opens the selected folder; an empty browser workbench shows
  onboarding rather than errors from an assumed local sidecar.

### V04-02 — Safe native filesystem and external changes

- Paths: filesystem adapter, Tauri capabilities, and required Rust FS commands.
- Read/write bytes, create directories, rename, and delete within authorized roots.
  Handle symlinks, case sensitivity, revoked permissions, and moved folders.
- Use safe replacement where supported, verify base revision before overwriting,
  and observe external changes. Preserve dirty buffers when the file changes externally.
- **Acceptance:** F01 hashes survive; path/symlink escapes cannot exceed granted access.
  External changes reload clean buffers or produce a recoverable conflict. Denied
  writes never mark documents saved.

### V04-03 — Window lifecycle and session recovery

- Paths: desktop bootstrap, Tauri events, session/recovery controllers.
- Handle closing/quitting with pending saves, recent-project reopening, and missing
  folders. Drain writes on normal close and retain drafts for forced termination.
- Check macOS keyboard conventions and resume after sleep. Losing focus is not
  permission to discard unsaved work.
- **Acceptance:** A04 runs in the actual app, including denied save on close, restart,
  and moved project folder. Reopening leaves no orphan views/listeners.

### V04-04 — Toolchain detection and process contract

- Paths: native `terminal.rs`, core terminal adapters, and shared process contracts.
- Detect Node/npm/Git/shell when launched from Finder; show versions, actual executable
  paths, and guidance if missing. Do not silently install/download executables.
- Establish cwd/arguments/environment/output/exit/cancellation contracts. Retain child
  handles, clean process trees, and decode UTF-8 incrementally. Terminal UI arrives in 0.9.
- **Acceptance:** start/interrupt a fixture process and verify actual exit; Unicode split
  across output chunks stays intact. An app without Node still edits files.

### V04-05 — Installed test and proven duplicate removal

- Paths: desktop scripts, src-tauri, terminal/sidecar implementations and documentation.
- Package a development macOS artifact and test without monorepo dev servers running.
- Remove only backends with no remaining consumers after migrating their tests/uses;
  update associated scripts and developer instructions.
- **Acceptance:** filesystem works without manually started sidecars; adapter contract
  tests pass. Document the canonical backend and reasons for retained alternatives.
  Stable signing/notarization remains explicitly pending for 0.15.

## Exit demonstration

Launch from Finder, choose a folder, edit TS, preserve binary assets, receive an
external change, and restart without any `bun dev` process. Missing Node/Git produce
useful states rather than making the editor unusable.
