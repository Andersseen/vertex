## The boundary that matters

The editor is not a miniature IDE. Preview, Git, filesystems, terminals, and
deployment belong to product workbenches. Keeping that boundary lets the
embedded editor stay useful in learning platforms, documentation, demos, and
application-specific tools without inheriting the full Vertex runtime.
